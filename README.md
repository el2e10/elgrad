  # Elgrad
  
</div>

A deep learning framework to teach myself in depth about AI and DL. It started with the foundational code from Andrej Karpathy's [micrograd](https://github.com/karpathy/micrograd), 
and I drew further inspiration from George Hotz's [tinygrad](https://github.com/tinygrad/tinygrad) project.
